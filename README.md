# Сравнительный анализ алгоритмов исправления опечаток (CourseWork2026)

Учебный проект на C++20 для реализации и сравнительного бенчмаркинга классических алгоритмов автоматического исправления опечаток в словах русского языка (с поддержкой UTF-8).

## Реализованные алгоритмы

Все алгоритмы наследуются от общего абстрактного класса `Solver` (`Solver.h`), который также реализует декодирование UTF-8 строк в массив Unicode code points (`utf8_to_codepoints`) для корректной посимвольной работы с кириллицей.

1. **Алгоритм Левенштейна (`LevenshteinSolver`)** — вычисление классического редакционного расстояния методом динамического программирования (вставка, удаление, замена символа).
2. **Алгоритм Дамерау — Левенштейна (`DamerauLevenshteinSolver`)** — расширение редакционного расстояния с учётом транспозиции (перестановки) двух соседних символов.
3. **Триграммный метод (`TrigramSolver`)** — построение инвертированного индекса по символьным триграммам слова (с паддингом `__word_`) и ранжирование кандидатов по коэффициенту Жаккара.
4. **Метод зашумлённого канала (`NoisyChannelSolver`)** — вероятностное ранжирование кандидатов, полученных от базового алгоритма (в `main.cpp` используется `DamerauLevenshteinSolver`), на основе частотного словаря с логарифмированием и сглаживанием Лапласа (+1).

## Метрики оценки

В `main.cpp` для каждого алгоритма на всех тестовых выборках (`test10` – `test5000` и `test5000many`) замеряются:

- **Accuracy@1 (%)** — доля случаев, когда правильное слово оказалось на первом месте среди кандидатов.
- **Accuracy@3 (%)** — доля случаев, когда правильное слово попало в топ-3 кандидатов.
- **Среднее время работы (мс)** — среднее время обработки одного слова (измеряется через `std::chrono::high_resolution_clock`).

## Сборка и запуск

### Требования

- Компилятор с поддержкой **C++20** (`g++`, `clang++` или MSVC)
- **CMake** (в `CMakeLists.txt` указана минимальная версия `3.31`; при необходимости строку `cmake_minimum_required` можно понизить до установленной версии CMake, например `3.16+`)

### Сборка через CMake (Linux / Windows)

```bash
git clone https://github.com/MmichailM/CourseWork2026.git
cd CourseWork2026
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

При сборке CMake автоматически копирует папку `input_data/` в директорию сборки.

### Запуск

```bash
cd build
./main
```

> **Совет:** для бенчмарков на выборках из 5 000 слов рекомендуется собирать проект именно в режиме `Release` (`-O3`), иначе время выполнения в Debug-сборке будет значительно выше.

### Ручная проверка одного слова

В `main.cpp` закомментирован пример точечной проверки одного слова с подробным выводом кандидатов и оценки:

```cpp
Result res = ls.solve("разраоткба");
ls.printResult(res);
```
